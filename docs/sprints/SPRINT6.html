מודולים שנבנים בספרינט

מה הצוות בוחר: Zoom API או Google Meet API — המפתחות יבחרו את האפשרות הפשוטה יותר לאינטגרציה. אין העדפת לקוח. (SPEC §11.1)

Backend — יצירת פגישה

endpoint חדש שיוצר פגישה דרך Zoom/Meet REST API ומחזיר קישור הצטרפות. שומר מזהה הפגישה + timestamp + תא רלוונטי. מגביל גישה: מקצוען או מנהל בלבד.

Backend — שליחת הזמנות

לאחר יצירת הפגישה — שליחת הזמנת מייל לכל חברי הקבוצה/מגזר המדויקים. הקישור חד-פעמי. AuditLog על כל פגישה שנפתחה.

Frontend — פתיחת פגישה

ממשק לפתיחת פגישה — בורר קבוצה/מגזר, שדה נושא, כפתור "פתח שיחה". גלוי למקצוען ולמנהל בלבד. מציג אישור עם הקישור לאחר היצירה.

Frontend — הצטרפות לפגישה

לחצן "הצטרף לשיחה" מופיע בממשק המשתמש כאשר יש פגישה פעילה לקבוצה שלו. הקישור עובר דרך המערכת ולא משותף ישירות.
