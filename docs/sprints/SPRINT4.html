4

חוקי Angular — תזכורת

Smart / Dumb Components

Container component אחד לכל feature — הוא מביא נתונים ומעביר ל-Presentational components. Presentational components לא קוראים ל-service ישירות.

Services ו-HTTP

כל קריאת HTTP יוצאת אך ורק מ-service. Component לא קורא ל-HttpClient ישירות. השגיאה מטופלת ב-service ומועברת למעלה.

Route Guards

כל route מוגן ב-RoleGuard. מבקר רואה רק /moderator/**, איש מקצוע — /professional/**, מנהל — /admin/**. נתיב ללא guard לא עולה ל-PR.

Reactive Forms

טפסים עם שדות מרובים (שאלה, תשובה, הוספת מבקר) בנויים עם ReactiveFormsModule. Template-driven forms — רק לטפסים של שדה אחד.

Interceptors

ה-AuthInterceptor מוסיף את ה-token לכל בקשה. אין לשלוח header ידני מה-component. ה-interceptor כבר מוגדר — פשוט להשתמש ב-service.

Privacy by Design

שם מלא של שואל לא מוצג לאיש מקצוע אלא אם checkbox "חשוף שמי" סומן. קטלוג מציג שמות ותחומים בלבד — ללא פרטי קשר.

  • Admin מוסיף/מסיר מבקר — שינוי מופיע מיידי בטבלה
  • כל route חדש מוגן ב-RoleGuard המתאים
  • טפסים (שאלה, תשובה, הוספת מבקר) בנויים עם ReactiveFormsModule

Deployment

  • Frontend נגיש בURL ציבורי על Vercel
  • Backend נגיש בURL ציבורי על Render
  • Login, הרשמה, ופורום עובדים על ה-URL הציבורי
  • Environment variables מוגדרים בפאנל הענן — לא ב-code
✅ סיום ספרינט 4 = האפליקציה נגישה לכולם, עם RBAC מלא — שלושת התפקידים (מקצוען, מבקר, מנהל) מחוברים ועובדים.
