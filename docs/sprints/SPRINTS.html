[מנהל א' אישר] — Sprint 2 ↓

ממתינה למנהל ב'
↓ [מנהל ב' אישר] ↓

RBAC — מי מקבל גישה מתי

ארבעה תפקידים, חמישה ספרינטים. הטבלה מראה מה כל תפקיד יכול לעשות בכל ספרינט.

תפקיד Sprint 1 Sprint 2 Sprint 3 Sprint 4 Sprint 5 Sprint 6
👤 User
משתמשת רגילה		 הרשמה + כניסה + OTP המתנה לאישור. מייל: אושרת / נדחית / נדרש מידע קריאת פוסטים מסוננים לקבוצה/מגזר. כתיבה + עריכה + מחיקה שלה. דיווח על פוסטים שאלה מקצועית (פרטית/ציבורית). צפייה ב-Q&A feed הודעות פרטיות לאותה קבוצה/מגזר. AI Agent (זכויות חד-הורי). ממשק עברית/אנגלית. מחיקת חשבון הצטרפות לשיחת וידאו קבוצתית (פגישות שנפתחו ע"י מקצוען/מנהל)
🛡️ Admin
מנהלת		 — אישור / דחייה / בקשת מידע / השעיה. ניהול מנהלים שניים. SLA tracking broadcast לכל הקהילה. גישה לכל ההודעות ללא הגבלת קבוצה/מגזר הוספת / עריכת / הסרת מבקרים ואנשי מקצוע Audit Log מלא + פילטרים + ייצוא CSV פתיחת פגישת וידאו לכל קבוצה/מגזר. הזמנות אוטומטיות למשתתפים
🔍 Moderator
מבקרת		 — — קבלת התראות דיווח (שלב 1+2). הסתרת הודעות טיפול בדיווחים בתאים שלה. כרטיס משתמש. השעיה ידנית. זיהוי חריגות — —
💼 Professional
איש מקצוע		 — — — קבלת שאלות (לפי תחום / ספציפי). מענה + הבהרה. Q&A feed — פתיחת פגישת וידאו קבוצתית לפי קבוצה/מגזר. הזמנת משתתפים דרך המערכת
💡 הסינון לפי קבוצה × מגזר הוא שכבה נוספת מעל ה-RBAC. גם User בתפקיד ACTIVE רואה רק את הפורום של הקבוצה/מגזר שלה (אלמנה-חסידית רואה רק פוסטים לאלמנות-חסידיות או לכלל האלמנות או לכולם).
